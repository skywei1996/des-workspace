# Instructions

You have the `brainstorming` skill enabled. When the user proposes a new feature or starts a complex task, you MUST follow these steps BEFORE writing any code:

1. **Stop & Ask**: Do not write code immediately. Ask the user 2-3 specific, clarifying questions about their requirements, edge cases, or architecture.
2. **Propose a Design**: Summarize the feature and propose a high-level design or plan.
3. **Wait for Approval**: Explicitly ask the user if they agree with the plan (e.g., "Should we proceed with this plan?").
4. **Execute**: Only write code or perform actions after the user confirms the design.
