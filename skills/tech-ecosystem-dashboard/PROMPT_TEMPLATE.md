## Fast Starter For Technical Matrix

```md
请基于 tech-ecosystem-dashboard skill，生成一张 Claude Code 技术蓝图板，输出单文件 HTML。

要求：
- 这是技术矩阵图，不要主展示大图，不要中心大图
- 参考高端工业蓝图板风格，不要做成普通表格
- 必须使用模块化蓝图布局，不要整页横条带
- 以左侧流程区、中部平台能力区、右侧场景区、底部生态/基础区为主
- 单屏 16:9

主题标题：Claude Code 技术矩阵图
副标题：智能辅助编码与自主工程能力矩阵
一句话价值主张：矩阵化展示 Claude Code 的核心能力、技术层次、集成方式与工程价值。

行维度：交互接入 / 语义理解 / 推理执行 / 工具集成 / 安全治理
列维度：核心能力 / 接口形式 / 运行环境 / 输出结果

版式结构：顶部价值带 + 左侧流程区 + 中部核心平台区 + 右侧场景区 + 底部生态/基础治理区

顶部价值区：深度代码理解 / 安全执行 / 自主编程 / 工程生态兼容

左侧流程区：接入 -> 理解 -> 规划 -> 执行 -> 治理

核心平台区：
- 交互接入模块：CLI / 编辑器集成 / 命令触发
- 语义理解模块：代码解析 / 上下文理解 / 依赖识别
- 推理执行模块：任务规划 / 多步修改 / 验证执行
- 工具集成模块：GitHub / VSCode / Shell / Runtime Bridge
- 安全治理模块：Sandbox / Policy / Secure Execution

对比区：Claude Code / 传统 IDE / 普通 AI Copilot
场景区：代码重构 / 自动修复 / 工程协作 / 安全执行
生态区：VSCode / GitHub / Anthropic API / Docker
基础区：Runtime / Workspace / Cache / CLI / API / Sandbox / Policy

视觉要求：深色；客户色优先；无则蓝绿色工业系；按分区分色
板式审美要求：强标题条；清晰模块分区；图文混排；场景区必须有缩略图或示意图占位；不要整片同质黑框
强约束：结果必须一眼看出是高端技术蓝图板，而不是普通表格或简陋矩阵；不要整页横条带
```
