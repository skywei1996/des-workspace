# ETSCN 850002 Forecast

本 skill 仅用于 `850002` 工作表的数据填写流程。它适用于已经验证过的 ETSCN PL Rolling Forecast 与 NAE P&L Rolling Forecast 模板组合，例如：

- `SICO 测试 总表 ETSCN PL Rolling Forecast-数字员工.xlsx`
- `NAE P&L rolling forecast-数字员工.xlsx`

目标是从 NAE 源工作簿读取可确定匹配的数据，填写到 ETSCN 目标工作簿的 `850002` sheet 中。

## 使用原则

- 只写入能够确定匹配的单元格。
- 不编造、不推算、不外推任何值。
- 如果源单元格为空，目标单元格保持不变。
- 如果行无法高置信匹配，目标单元格保持不变。
- 默认保存为新文件，不覆盖原始目标工作簿，除非用户明确要求覆盖。
- 默认只填写目标中当前为空的单元格；已有值或公式保持不变。

## 适用场景

当用户需要执行以下任务时使用本 skill：

- 将 NAE P&L rolling forecast 的 `850002` 数据复制到 ETSCN PL Rolling Forecast 的 `850002` sheet。
- 刷新 ETSCN `850002` sheet 中缺失的 forecast 数据。
- 按既定映射同步 2026 年月份数据、KPI、现金流、HC/岗位人数等内容。
- 处理月份格式对齐，例如 `2026年4月`、`4/1/2026`、`2604` 之间的匹配。

## 不适用场景

不要在以下情况下使用本 skill：

- 工作表不是 `850002`。
- 源文件或目标文件的布局与已验证模板存在明显差异。
- 需要处理其他 entity、其他 sheet 或其他 forecast 模板。
- 用户要求生成缺失 KPI、合成人数、推算空白月份。
- 固定映射尚未更新，却要处理新行、新字段或新结构。

## 必需输入

执行前需要确认：

- 目标工作簿：包含 ETSCN PL Rolling Forecast 格式的 `850002` sheet。
- 源工作簿：包含 NAE P&L Rolling Forecast 格式的 `850002` sheet。
- 用户是否允许覆盖原文件；若未明确允许，必须输出为新文件。

## 工作流程

1. 确认用户要从 NAE 源工作簿填写 ETSCN 目标工作簿的 `850002` sheet。
2. 确认用户已通过平台上传源工作簿和目标工作簿附件。
3. 默认生成新的目标工作簿副本；如果平台支持命名，输出文件名使用 `<目标工作簿名>_已填写.xlsx`。
4. 处理完成后，核对代表性单元格：至少包含一个月度值、一个 KPI 值、一个现金流值、一个 HC/岗位人数值。
5. 向用户报告输出文件名称或下载入口、写入单元格数量，以及因未匹配或源为空而保持不变的范围。

## 固定匹配规则

必须严格按本 Skill 定义的固定映射匹配行。该映射来自已验证工作簿组合，包含以下重命名概念：

- `服务成本` <- `成本合计`
- `KPI净利润` <- `贡献利润`
- `KPI 净利率 CM（%）` <- `贡献利润率 CM（%）`
- `HC汇总` <- `总计人员数量`
- `实施人员` <- `实施人员数量`
- `管理人员` <- `G&A`
- `销售人员` <- `Sales`
- `研发人员` <- `R&D`

## 月份与列映射

必须严格应用以下列映射：

- 目标主 2026 区块：`CZ:DP` <- 源 `BW:CM`
- 目标独立列：`DT`，即 `2026年4月` <- 源 `CA`，即 `4/1/2026` 或 `2604`

写入规则：

- 仅当源值非空时写入。
- 仅当目标单元格当前为空时写入。
- 目标已有值、公式、人工填充内容默认不覆盖。
- 未匹配行、源为空、目标已有内容，全部保持不变。

## 岗位/人数口径

处理 HC 与岗位人数时，必须使用固定口径：

- `HC汇总` 对应源表 `总计人员数量`
- `实施人员` 对应源表 `实施人员数量`
- `管理人员` 对应源表 `G&A`
- `销售人员` 对应源表 `Sales`
- `研发人员` 对应源表 `R&D`

不要根据岗位名称相似度临时猜测新增岗位；如果出现本 Skill 映射之外的岗位，保持目标不变并在结果中说明。

## 平台使用方式

用户通常通过浏览器或平台文件上传入口提供工作簿附件。执行时应读取用户上传的文件

需要的上传文件：

- 源工作簿：NAE P&L Rolling Forecast。
- 目标工作簿：ETSCN PL Rolling Forecast，且包含 `850002` sheet。

处理完成后，应生成一个新的 Excel 文件供用户下载。默认输出文件名为：

```text
<目标工作簿名>_已填写.xlsx
```

不要要求用户使用命令行运行；不要假设文件存在于任何本地磁盘路径或 Skill 目录路径中。

## 验证要求

处理完成后至少检查以下代表性单元格：

- `DD4`：2026 年 4 月服务收入或代表性月度值对齐。
- `DT4`：独立 2026 年 4 月列与源 `CA` 对齐。
- `DD31`：KPI 净利润。
- `DD34`：现金流入。
- `DD42`：总 HC 或岗位人数汇总。

最终回复用户时必须包含：

- 输出文件名称或下载入口。
- 写入单元格数量。
- 是否存在未匹配、源为空、目标已有值而保持不变的内容。
- 如果无法处理，说明原因，例如未上传源/目标工作簿、缺少 `850002` sheet、模板结构明显不匹配、平台无法生成 Excel 文件或文件被占用。

## 安全边界

- 不覆盖原文件，除非用户明确要求。
- 不删除工作簿中的公式。
- 不修改 `850002` 之外的 sheet。
- 不用模糊匹配覆盖固定映射。
- 不对空白源数据进行填补、估算或延展。
