# 对话区文件预览验收标准

| 项目 | 内容 |
| --- | --- |
| 功能名称 | 对话区文件预览与下载 |
| 所属版本 | 2026 H2 |
| 验收范围 | 对话中生成或返回文件后的文件列表、预览和下载 |
| 支持格式 | Word、PPT、Markdown、HTML、Excel、PDF、JPG；CAD 等特殊格式使用 JPG 预览 |
| 文档状态 | 待验收 |

> 术语约定：Word、PPT、Markdown、HTML、Excel、PDF、JPG 分别指 `.docx`、`.pptx`、`.md`、`.html`、`.xlsx`、`.pdf`、`.jpg/.jpeg` 文件。CAD 等特殊格式指无法原生渲染、但可以通过静态图片预览的文件。

## 一、验收重点

1. 文件生成或返回成功后，当前对话展示文件名称、格式、大小和操作入口。
2. 预览区左侧展示本会话内的文件列表，文件之间可以切换且不串内容。
3. 各支持格式使用适配的预览方式；CAD、DWG、DXF 等特殊格式使用对应 JPG 预览，但下载原始文件。
4. 用户可以在当前对话中预览和下载文件，预览失败时仍保留有效的原文件下载入口。
5. 左侧文件目录支持收缩和恢复，操作不丢失当前文件和预览状态。
6. 文件访问受用户、会话和文件权限控制，不泄露内部路径或其他会话文件。

## 二、页面功能验收

| 编号 | 功能点 | 通过标准 | 级别 |
| --- | --- | --- | --- |
| UI-01 | 本会话文件列表 | 预览区左侧仅展示当前会话已生成或返回、且当前用户有权限访问的文件 | 阻断 |
| UI-02 | 文件信息 | 文件列表或文件卡片展示可识别的文件名、正确扩展名、格式和文件大小 | 阻断 |
| UI-03 | 文件类型标识 | Word、PPT、Markdown、HTML、Excel、PDF、JPG 和特殊格式有清晰的类型标识 | 重要 |
| UI-04 | 当前选中状态 | 当前文件有明确选中状态，切换后文件名、预览内容、大小和下载地址同步更新 | 阻断 |
| UI-05 | 多文件切换 | 同一会话存在多个文件时，可以通过左侧文件名切换，文件内容和操作状态不串用 | 阻断 |
| UI-06 | 空目录 | 本会话没有文件时展示空状态，不展示其他会话的文件 | 重要 |
| UI-07 | 预览区域 | 选中文件后在右侧打开稳定的预览区域，内容不被遮挡、截断或挤出页面 | 阻断 |
| UI-08 | 收缩目录 | 左侧目录可以收缩，收缩后预览区域自动扩展，当前文件和预览内容不刷新、不丢失 | 重要 |
| UI-09 | 恢复目录 | 左侧目录可以重新展开，文件列表、选中状态和预览内容保持不变 | 重要 |

## 三、格式预览验收

| 文件类型 | 扩展名 | 预览要求 | 级别 |
| --- | --- | --- | --- |
| Word | `.docx` | 标题、段落、列表、表格、分页和主要图片可阅读，结构无明显错位 | 阻断 |
| PPT | `.pptx` | 多页幻灯片可查看和切换，标题、正文、图片、表格和图表可辨识 | 阻断 |
| Markdown | `.md` | 标题、段落、列表、表格、引用、代码块、链接和图片按语义渲染；代码不执行 | 阻断 |
| HTML | `.html` | 在受控区域展示页面布局、文字、图片和图表；相对资源可加载，脚本不影响宿主页面 | 阻断 |
| Excel | `.xlsx` | Sheet 可切换，表头、数据、数字、日期、百分比、货币和公式结果显示正确 | 阻断 |
| PDF | `.pdf` | 页面不空白，多页可翻页或滚动，文字、图片、表格和中文字体可辨识 | 阻断 |
| JPG | `.jpg` / `.jpeg` | 图片按原始比例适应容器展示，大图可查看完整画面或放大查看，清晰度可接受 | 阻断 |
| CAD 等特殊格式 | `.cad`、`.dwg`、`.dxf` 等 | 不要求原生渲染；使用对应 JPG 静态图预览，并明确标识原始格式和预览格式 | 重要 |

## 四、下载验收

| 编号 | 验收项 | 通过标准 | 级别 |
| --- | --- | --- | --- |
| DL-01 | 下载入口 | 当前选中的文件始终有明确下载入口，预览失败时仍保留入口（用户有权限时） | 阻断 |
| DL-02 | 原始文件 | 下载文件的名称、扩展名、类型、大小和内容与原始文件一致 | 阻断 |
| DL-03 | 特殊格式下载 | CAD 等特殊格式下载原始 CAD 文件，不将 JPG 预览图作为原文件下载 | 阻断 |
| DL-04 | 重复下载 | 同一文件可以重复下载，下载失败时有明确反馈且可以重试 | 重要 |

## 五、异常与安全验收

| 编号 | 场景 | 通过标准 | 级别 |
| --- | --- | --- | --- |
| EX-01 | 文件不存在或被删除 | 预览和下载均提示文件不可用，不展示空白内容或虚假成功状态 | 阻断 |
| EX-02 | 文件损坏或格式不匹配 | 明确提示无法预览，不伪装成其他格式；有权限时保留原文件下载 | 阻断 |
| EX-03 | 预览超时或网络异常 | 结束加载状态并提示重试，不影响当前对话和其他文件操作 | 重要 |
| EX-04 | 权限失效 | 无权限用户不能通过预览或下载地址访问文件 | 阻断 |
| EX-05 | 会话隔离 | 用户不能查看其他用户或其他会话的文件、预览图或文件地址 | 阻断 |
| EX-06 | HTML 脚本安全 | HTML 预览不能访问宿主页面、用户凭据、系统 Prompt 或内部数据 | 阻断 |
| EX-07 | 特殊文件名 | 包含中文、空格、括号等字符的文件仍可正常预览和下载 | 重要 |

## 六、验收结论

Word、PPT、Markdown、HTML、Excel、PDF、JPG 以及纳入本期的 CAD 等特殊格式均完成预览和下载验证；本会话文件列表、文件切换、目录收缩、特殊格式 JPG 预览、原始文件下载和权限隔离均通过，且无阻断问题，方可判定本期功能通过。
