Platform-Native Agents (Google ADK Framework)

Non-Standalone Agents

Characteristics: created dynamically when invoked, with no pre-deployment required
Use cases: created by general users for personal usage
Design rationale: reduce the number of independently deployed agents and lower operations overhead

Standalone Agents

Characteristics: independently deployed and continuously running
Use cases: created by advanced developers and reused across multiple applications
Design rationale: standalone agents expose public invocation APIs so they can also be called by applications outside this platform

Agent observability: the Agent layer exposes standardized, unified invocation interfaces upward to the API layer and remains compatible with different backend logging platforms

Externally Integrated Agents

Compatible frameworks/platforms: LangChain / LangFlow, NVIDIA NIM, Agent Toolkit, Coze, Dify, and more

Integration approach: configure the access endpoint of an already deployed agent on another platform during agent creation.
