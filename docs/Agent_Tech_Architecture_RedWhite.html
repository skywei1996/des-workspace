平台原生 Agent（Google ADK 框架）

非独立部署的 Agent

特征：用户调用时动态创建，无需预先部署
适用场景：普通用户创建、个人使用
设计考量：减少独立部署 Agent 数量，降低运维成本

独立部署的 Agent

特征：独立部署，长期运行
适用场景：有经验开发者创建，多应用调用
设计考量：独立部署的 Agent 公布调用 API，在本平台外的其它应用也可调用

Agent 可观测性：Agent 层向上 API 层提供标准、统一的调用接口，并兼容不同后端记录平台

外部集成 Agent

兼容框架/平台：LangChain / LangFlow、NVIDIA NIM、Agent Toolkit、扣子、Dify 等

兼容方式：创建 Agent 时设置其它平台已部署 Agent 的访问端口。
