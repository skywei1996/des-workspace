1. Quick Start

If this is your first time using AI WORKMATE, start here.

Your organization may already provide public AI Workmates. In that case, you can select an existing worker and start a conversation without creating a new one first.

  1. Select a worker Choose an available public AI Workmate from the Team workspace and enter the collaboration view.
  2. Send the request Describe the task directly, for example: "Summarize this week's AI industry highlights."
  3. Create a reusable worker when needed If you repeat the same type of task frequently, create a dedicated AI Workmate.
  4. Add resources or tools when needed Use a Knowledge Base for documents, Skills for reusable workflows, and MCP Toolsets for external actions.
Recommendation Start with a conversation first, then formalize the workflow. Add worker configuration and resources only after the task pattern is stable.
Where to start If you need a dedicated worker, read "Create AI Workmate". If you already have a worker and want to understand how to submit requests, upload files, and receive results, read "Chat with AI Workmate".

2. Create AI Workmate

Create an AI Workmate when you want to standardize a recurring task and let the worker operate with the same role, process, and output format over time.

How to create a worker

  1. Open Team and enter AI WorkMate.
  2. Click New AI Workmate.
  3. Complete Basic Information.
  4. Configure Core Skills and resource bindings, then click Onboard.

Basic Information fields

Field Recommended input Purpose
Full Name Name the worker clearly, such as "ReportGenerator" or "RecruitmentResumeScreening". Helps users identify and select the correct AI Workmate.
Category Select the worker category, such as PM or Recruitment. Groups the worker under the right business area.
Tags Add keywords that help with search and filtering. Makes the worker easier to find and reuse.
Description Describe the worker's role and task scope in one concise paragraph. Clarifies what the worker is designed to do.
Model Select an available model, such as gpt-5-PM, after it has been configured in Model Configuration. Determines the underlying model used by the worker.
Instructions Define the role, goals, workflow, output format, and constraints. Controls how the worker understands the task and produces results.

How to choose Core Skills

⚙️ planner Use this when the worker should break down the task, create steps, and plan before execution.
🔍 search Use this when the worker needs web search or recent public information, such as market news or competitor updates.
Selection guidance Enable planner when the worker needs structured reasoning and step planning.
Enable search when the worker must retrieve up-to-date public information.
Do not enable every skill by default. Select only what the task requires.

How to configure resources

Extended Skills Add reusable business workflows, such as a weekly report process or brainstorming workflow.
Knowledge Bases Bind prepared document collections when the worker needs product materials, policies, or presales references.
MCP Toolsets Bind external tool capabilities when the worker must access enterprise services, web tools, or other systems.
Recommended configuration order Complete Basic Information and Instructions first, then add advanced resources only when required:
  • Recent public information: enable search.
  • Reusable workflow: add an Extended Skill.
  • Private document reference: bind a processed Knowledge Base.
Instructions writing guidance
  • Role: define who the worker is, such as "You are an enterprise-level Product Manager."
  • Goals: state the expected result, such as "Produce five key insights."
  • Workflow: describe the order of work, such as collect, classify, analyze, and summarize.
  • Output format and constraints: specify tables, bullet points, length limits, and rules against unsupported claims.
Adjustment note: worker quality depends primarily on the Instructions. If the output is unstable, improve the role, workflow, and constraints before adding more tools.

3. Chat with AI Workmate

Use the collaboration view to send tasks directly to a selected AI Workmate. You can also attach files or images when the task requires additional context.

ReportGenerator

Typical use cases

Information organization Example: "Organize these meeting notes and extract five conclusions and three action items."
Content generation Example: "Use this product material to draft an external product introduction."
Research analysis Example: "Summarize this week's AI industry updates by company, product, and trend."
File-based tasks Example: upload a document and ask: "Read this file and list the summary and risks."

How to write a request

  1. Start with the task goal, such as "Generate a weekly report summary."
  2. Define the scope, such as "Only use this week's new information."
  3. Specify the output format, such as "Return a table and keep it within one page."

4. Knowledge Base

A Knowledge Base is used to provide an AI Workmate with domain-specific documents and proprietary reference materials. Use it when the worker must answer based on internal documents, terminology, and approved sources.

When to use a Knowledge Base Temporary file upload is suitable for one-off tasks, such as reviewing a single contract or summarizing today's meeting notes.
Knowledge Base is suitable for reusable, team-level document collections, such as policies, sales playbooks, product manuals, and HR materials.

Knowledge Base configuration steps

  1. Create Knowledge Base Open Resources > Knowledge Base, click New Knowledge Base, then fill in Name and Description.
  2. Import Documents Open the Knowledge Base detail page, click Import Documents, and upload files for processing.
  3. Bind the Knowledge Base to a worker Return to New AI Workmate or an existing worker configuration, then add the processed Knowledge Base under Knowledge Bases.

Knowledge Base maintenance principles
  • Keep scope focused: create separate Knowledge Bases by responsibility, such as policies, product manuals, or presales materials.
  • Refresh outdated content: remove obsolete regulations, expired campaign files, and outdated documentation regularly.
  • Bind only processed sources: if a Knowledge Base does not appear in the worker configuration, confirm that document processing has completed.

5. Skills

Skills are reusable business capabilities that can be attached to an AI Workmate. Use them to standardize recurring workflows, formats, and operating procedures.

Skills
Update Skill
How to understand Skills A Skill is not just a small action. It can package a stable business process, including the trigger condition, expected inputs, workflow steps, and output format, so the same capability can be reused across workers.
Skill authoring best practices
  • Single responsibility: each Skill should handle one clear capability or workflow.
  • Reusable process: turn frequently repeated analysis frameworks or output templates into Skills.
  • Define before configuring: clarify the trigger, inputs, workflow, and expected outputs before editing the Skill.

7. Model Configuration

Model Configuration manages the underlying models that can be selected when creating or updating an AI Workmate.

Model configuration steps

  1. Open Model Configuration Go to Settings > Model Configuration.
  2. Add model connection details Click New Model, then complete fields such as Name, Provider, Provider Type, Model Name, visibility, API endpoint, and credentials as required.
  3. Create and use the model Confirm that the connection details are correct, then click Create Model. The model can then be selected in the Model field when creating or updating an AI Workmate.
Change effective rule Changes to Model Configuration apply to newly started conversations and workflows. Tasks already running in the background continue through the original model connection and are not interrupted by mid-process configuration changes.
