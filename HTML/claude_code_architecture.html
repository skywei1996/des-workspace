Agentic Coding Workflow
从请求到补丁交付的执行闭环
WORKFLOW
1
Request Intake
统一接收 CLI、IDE 与仓库上下文，识别目标与边界。
2
Plan & Task Control
拆分任务、规划工具序列，并决定是否分派子代理。
3
Context Assembly
拼装仓库、记忆与缓存片段，形成执行上下文。
4
Tool Runtime Loop
调用搜索、编辑、shell、测试与 MCP，执行 TAOR 循环。
5
Review & Patch
输出 diff、解释变更并跑局部验证。
6
Deliver & Learn
答复落盘并回写经验，为后续任务缩短路径。
