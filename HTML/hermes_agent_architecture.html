Typical Hermes Workflow
典型运行链路
FLOW
1
Request Intake
chat、task、automation、workflow_run 的请求统一进站。
2
Plan / Clarify / Route
Planner 决定 direct、plan 或 clarify，并选出 skills 与后续执行路径。
3
Execution Loop
ExecutionAgent 调用工具、搜索、MCP、文件与任务能力，收集 observation。
4
Artifact / State Update
工作区文件、任务状态、workflow log 与执行记录同步更新。
5
Deliver / Terminate
返回最终答复或单一澄清问题，结束当前控制回合。
