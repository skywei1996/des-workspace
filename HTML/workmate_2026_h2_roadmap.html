两条标杆流程

验证产品是否真正进入企业业务

售前售后流程｜复制型标杆

验证跨系统、多步骤、多 Agent 协同，以及标准组件在第二客户或同类场景中的复用。

受理 → 知识检索 → 数据库查询 → 处理建议 → 工单更新 → 结果通知

经营分析流程｜正式交付

验证数据库访问、确定性计算、报告生成、结果确认和业务回写能力，满足标准化交付要求。

查询数据库 → 计算指标 → 生成报告 → 提交 / 回写

商业化结果｜12 月正式交付

首个客户验证业务闭环，沉淀连接器、Workflow、Skill、规则和模板，形成第二客户复制基线。

首个客户 → 标准组件 → 第二客户 → 可复制交付
