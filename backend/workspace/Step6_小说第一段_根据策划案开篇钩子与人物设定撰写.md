# 小说《先婚后爱》第一段

夜色笼罩着城市的玻璃天际线，灯光在雨后的街面上碎成一地冷光。顾清砚站在会议室的落地窗前，指尖还残留着文件纸的温度。她的项目被临时撤换，理由是“高层决定”，而她知道，那不过是权力游戏里的一次性牺牲。

她转身，目光落在那位新任合作方代表——沈砚舟。男人西装笔挺，神情冷淡，语气里带着不容置疑的克制：“顾小姐，如果你还想保住这个项目，我们可以谈一笔交易。”

顾清砚微微一笑，那笑意冷静得近乎锋利：“沈总的交易，向来不只是利益吧？”

空气在两人之间凝成一线张力。她的理性与他的克制，在这场无声的对峙中，仿佛预示着一场无法回避的纠缠。窗外的雨重新落下，城市的光影被打碎，命运的齿轮在此刻悄然转动。
